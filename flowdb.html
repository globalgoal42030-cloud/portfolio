Overview

Architecture

FlowDB is built around a custom LSM-tree (Log-Structured Merge-tree) storage engine that separates write-heavy ingestion from read-optimized query paths. The Raft consensus layer ensures fault-tolerance across distributed nodes, while columnar compression reduces on-disk footprint by up to 94% compared to row-oriented storage.

LSM-Tree Engine
Custom write-optimized storage with tiered compaction and bloom filters for O(1) key lookups at scale.
Raft Consensus
Leader election and log replication across nodes ensures zero data loss and strong consistency guarantees.
Columnar Compression
Time-series data stored column-wise with delta encoding and LZ4 compression — 94% space reduction.
gRPC Interface
High-performance Protobuf-based API supporting streaming reads, batch writes, and subscription queries.
Query Planner
Cost-based optimizer with time-range pruning and pre-aggregated rollup caches for common intervals.
Horizontal Sharding
Automatic range-based sharding by time partition with rebalancing support for elastic scaling.
Usage

Quick Start

// Connect to FlowDB client, err := flowdb.Connect("localhost:7432", flowdb.Options{   Timeout: 5 * time.Second,   TLS: true, }) // Write tick data err = client.Write(ctx, flowdb.Point{   Metric: "btc.usd.price",   Timestamp: time.Now(),   Value: 67482.50,   Tags: map[string]string{"exchange": "coinbase"}, }) // Query last 5 minutes rows, err := client.Query(ctx, ` SELECT mean(value), max(value) FROM "btc.usd.price" WHERE time > now() - 5m GROUP BY time(10s) `)
