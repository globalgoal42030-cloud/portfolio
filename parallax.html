Architecture

How it works.

Parallax uses Conflict-free Replicated Data Types (CRDTs) to allow multiple users to edit dashboards simultaneously without merge conflicts. Each operation is a commutative, associative transformation applied locally and synced via WebSockets. Redis pub/sub handles real-time fan-out while PostgreSQL stores the canonical state.

CRDT Sync Engine
Every widget, layout change, and data binding is a CRDT operation — mergeable in any order without conflicts.
WebSocket Layer
Persistent connections per user with heartbeats, reconnection logic, and optimistic local state updates.
D3.js Renderer
Custom D3 chart components with declarative bindings — users connect live data sources to any visual type.
Auto-Scaling Infra
Kubernetes HPA triggered on WebSocket connection count — scaled from 2 to 40 pods during peak.
Permission Model
Row-level security in PostgreSQL with workspace, dashboard, and widget-level access controls.
Data Connectors
Native connectors for PostgreSQL, BigQuery, Snowflake, REST APIs, and CSV uploads.
