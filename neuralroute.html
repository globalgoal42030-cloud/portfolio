Overview

Intelligent routing.

NeuralRoute sits in front of your microservice mesh as an Envoy-compatible filter. It observes real-time latency, error rates, and request context, then uses a contextual bandit algorithm to choose the optimal upstream for each request. The model retrains online every 60 seconds with no downtime — routing decisions improve continuously without human intervention.

Contextual Bandit
LinUCB algorithm balances exploration vs. exploitation — discovers faster upstreams without degrading traffic.
Envoy Integration
Deployed as a native Envoy WASM filter — zero extra network hop, sub-2ms routing decision overhead.
Online Retraining
Model updates every 60 seconds using a sliding window of recent request outcomes — adapts to traffic shifts in real time.
Rust Core
Hot path written in Rust for deterministic low-latency inference — Python handles offline training and model export.
Observability
Prometheus metrics, per-route latency histograms, model confidence scores, and Grafana dashboards included.
Kubernetes Native
Helm chart with HPA support — scales sidecar instances automatically based on request throughput.
